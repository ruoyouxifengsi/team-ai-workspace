# 心路实践团使用报告

> 北京科技大学心路实践团（5-10 人）在 2026 年 5 月部署并开始使用本系统的现场记录。本文记录的是**开发部署过程 + 头一两周的使用反馈**。等暑期实践活动完整跑完一轮，会补一份更完整的复盘。

---

## 背景

心路实践团是北科大的一个本科生暑期社会实践小组，每年招新 10 人左右，活动期 6-8 月。日常需要做的工作集中在文字密集型场景：

- 招新推文 / 活动方案
- 历届方案、评委关心点、章程的资料检索
- 调研数据整理（xlsx）
- 课程设计、推广文案的反复迭代

之前队员把材料散在微信群、QQ 群、个人云盘里，每年新人入组都要重新捋一遍历史资料。希望有个统一的地方放历届资料、人人都能用 AI 助手快速完成文字工作。

---

## 为什么自己搭，不用现成的 SaaS

- **数据涉及实名招新材料**，不放心传第三方
- **预算紧**：5-10 人的团队不愿意承担 ChatGPT Team 月费
- **想沉淀历届资料**：商业 SaaS 不便于团队成员共享知识库
- **想加自定义工具**：未来比如「按学院搜简历」这种内部场景

队长（也是这套系统的开发者）自己有 Python 后端 + React 前端基础，愿意花一周搭。

## 开发过程

整套代码从零到上线**约 7 天净开发时间**，其中：

- **M1（基础骨架）**：4 天。账号系统 + 文件上传/下载/权限隔离 + 部署
- **M2（AI 对话核心）**：3 天。9 个工具 + agent loop + 三栏 UI + 配额机制

开发协作方式：**Claude Code subagent-driven development**。流程：

1. **brainstorm** — 用 Claude 的 brainstorming skill 跟它讨论需求 / 范围 / 边界，产出一份 spec markdown
2. **writing-plans** — 让它写一份分到具体任务的实施计划（M1 有 28 个 Task，M2 有 41 个 Task）
3. **subagent-driven execution** — 主 Claude 调度 subagent 一个个干：每个 task 派一个实现 agent（写测试 → 看红 → 写实现 → 看绿 → commit），然后派 spec compliance reviewer 验证符合 plan，再派 code quality reviewer 看代码质量。两层 review 全过才进下一个 task
4. **review at phase boundary** — 每 5-10 个 task 做一次 phase-level review，发现问题立即修

最终代码状态：

- 后端 121 个 pytest 全过、ruff lint 全过
- 前端 17 个 vitest 全过、TypeScript 严格模式编译通过
- 总代码量约 3500 行（不含测试）

主要踩的坑见 [`DESIGN.md` 第 10 节](DESIGN.md#10-我们踩过的坑)。其中**「中国大陆运营商 DPI RESET 443 端口」**最坑——网站部署完一切正常，curl 内部测试 `/api/healthz` 返回 OK，但浏览器无论用家里 wifi 还是手机 4G 都打不开。Ping 通、TCP 握手通，TLS ClientHello 一发出去就被 RESET。最后定位是运营商对未备案域名的 SNI 过滤。临时方案换 8443 端口，URL 变成 `https://ai.xinlu-ai.xin:8443/`。备案排队中。

## 当前使用情况

> **数据时间**：部署上线 + 头两周。等暑期活动完整跑完会补一份更全的。

### 数量

- 注册账号：3（admin + 2 个测试队员；尚未正式拉队员入驻）
- 公共资料区文件数：0 → 持续上传中
- 已生成会话数：10+（含测试）
- 主要 token 消耗源：写招新推文草稿、读历届方案做总结

### 队员反馈（已收集）

- **"用着像 ChatGPT 但能读我上传的文件，方便"**：最常听到的肯定
- **"会话列表能切换太爽了，以前 ChatGPT 一锅烩"**：多会话设计被验证有用
- **"反馈按钮藏在右上角不显眼"**：UI 改进点，已记录
- **"想让 AI 同时编辑多个文件"**：v0.2 之后再考虑
- **"等待 AI 回复时不知道它在干什么"**：流式输出（v0.2）会缓解

### 已发现但未修的小问题

- 配额上限 100 万 token 对 5-10 人团队太宽松了，可以降到 50 万避免极端 case
- 上传按钮在窄屏被压扁
- SettingsPage 缺少"取消"按钮

## ROI 评估

- 服务器：75 元/月
- DeepSeek API：估算 20-50 元/月（5-10 人正常使用）
- 域名：60 元/年 ≈ 5 元/月
- **月成本约 100-130 元**

对比商业方案：

- ChatGPT Team 5 人最低 25 美元/人/月 = 125 美元/月 ≈ 900 元/月
- 自建 6-9 倍便宜，前提是有时间搭

但**自建的隐性成本**：
- 7 天开发时间（如果不用 AI 协作开发可能要 3 周）
- 8443 这种"运维异象"的随机时间投入
- 续期维护：升级 Docker / 续 Let's Encrypt / 监控备份

如果团队完全没人懂技术，去买 SaaS。

## 给想自己搭的同学

如果你的团队条件类似（5-15 人，文字密集型，预算紧，团里有人懂技术）：

1. **先 fork 这个 repo**，照 `README.md` 的快速开始本地跑起来玩半小时
2. **改 SYSTEM_PROMPT** 让 AI 适应你们团队的语气和场景
3. **上传 10-20 个历届资料**做种子库，让 search_public 工具有东西可搜
4. **拉 2-3 个核心队员先用一周**，再决定要不要全员上
5. **设个**：「AI 写的东西自己审一遍，不要照搬」的硬规矩

部署在大陆云的话提前申请 ICP 备案（7-20 工作日），不然只能 8443 凑合。

需要帮助可以提 issue（或者直接给我发邮件——但我维护能力有限，不保证响应速度）。
